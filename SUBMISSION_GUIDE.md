## Before uploading
- Add your name, student ID, institution and mentor to the report cover by editing the COVER fields in build_report.py, then regenerate the PDF.
- Check the actual rubric and deadline in your portal. Neither was supplied with this request.
- Read the limitations: this is a text-support prototype, not completion of the Gnani voice stage. If voice is mandatory, implement it and collect genuine end-to-end evidence before claiming compliance.
- Run the commands in README.md and practice the demonstration. Review all AI-assisted work under your institution's rules.

## Public GitHub source (requires your account)
1. Confirm dataset redistribution permissions with your course.
2. Create a new repository from your GitHub account and choose Public.
3. Upload the project files, retaining folder structure. Keep .gitignore; exclude generated tickets, .env, .venv and __pycache__.
4. If data cannot be redistributed, omit dataset/ and instruct evaluators how to place their authorized dataset there.
5. Open the repository link in a private/incognito window, signed out, and confirm code and README are readable.
6. Paste the actual repository URL into the portal. Do not use an invented or placeholder link.
